# امرح وتعلّم 🎉
منصة ألعاب تعليمية للأطفال 6-12 سنة: رياضيات + عربي + إنجليزي + علوم.

## التشغيل محلياً
افتح `index.html` مباشرة في المتصفح.

## النشر على GitHub Pages
1. ارفع كل الملفات إلى مستودع GitHub.
2. من Settings > Pages اختر Deploy from a branch ثم `main` و `/ (root)`.
3. الرابط سيكون: `https://USERNAME.github.io/REPO/`

## الملفات
- `index.html` الواجهة
- `css/style.css` التصميم
- `js/app.js` منطق الألعاب والنقاط والشارات (محفوظة في localStorage)
